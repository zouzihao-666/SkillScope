# 字符长度与实际 token 用量

主实验各组具有相同的题目与重复次数。首阶段没有前序模型交接内容，便于比较固定输入；后续阶段的输入还受生成摘要和候选代码长度影响。下表仅核对用量，不推断性能因果关系。

| 配置 | 首阶段系统文本平均字符数 | 首阶段平均输入 tokens | 全阶段输入 tokens | 全阶段输出 tokens |
| --- | ---: | ---: | ---: | ---: |
| baseline | 313.0 | 475.8 | 23974 | 11845 |
| single-root-cause | 556.0 | 519.8 | 26809 | 13517 |
| single-minimal-fix | 560.0 | 524.8 | 24989 | 8594 |
| single-edge-cases | 577.0 | 529.8 | 27149 | 12939 |
| single-input-validation | 578.0 | 523.8 | 26502 | 11542 |
| single-compatibility | 565.0 | 518.8 | 25243 | 10346 |
| single-python-idioms | 623.0 | 536.8 | 25867 | 9620 |
| all | 1894.0 | 774.8 | 36566 | 14933 |
| scoped | 1073.0 | 610.8 | 29722 | 13042 |
| all-reversed | 1894.0 | 774.8 | 33608 | 13403 |
| length-a | 1894.0 | 821.8 | 37260 | 12471 |
| length-b | 1894.0 | 776.8 | 35777 | 12254 |

字符等长不保证分词后的 token 数相同；两种无关文本也可能影响模型。
