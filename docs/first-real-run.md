# 第 2 阶段：让模型真正做一道题

本阶段把实验台接上模型，并验证模型提交的代码是否正确。首次使用先读完，再运行命令。

## 1. 配置模型连接

复制 `.env.example` 为 `.env`，在本机编辑 `DEEPSEEK_API_KEY`。已有配置时跳过复制。

作用：告诉程序使用哪个账户调用接口。程序读取密钥，只把它放在 HTTPS 认证头中；不加入任务提示、日志或容器参数。`.env` 被 Git 忽略。

模型固定从 `examples/experiment.json` 读取，当前为 `deepseek-flash` 非思考模式。环境变量与 `.env` 的同名设置相比，环境变量优先。

如果终端找不到 Docker，在 `.env` 中填写 `SKILLSCOPE_DOCKER` 的完整路径；本机已确认路径为 `D:\docker\app\resources\bin\docker.exe`。程序会为 Docker 子进程补上同目录 PATH，确保凭据辅助程序也能找到，不修改系统 PATH。

## 2. 准备评分环境

```powershell
.\.venv\Scripts\python.exe -m skillscope sandbox-build
```

作用：构建一个只包含 Python 和执行入口的 Linux 镜像。可以把镜像看成每次开工前使用的统一工作台模板。首次需要下载基础镜像。

构建只发送 `sandbox_files` 目录，密钥和整个项目不进入构建上下文。基础镜像固定 SHA-256 摘要，运行时再记录实际镜像 ID。

## 3. 运行无技能配置

```powershell
.\.venv\Scripts\python.exe -m skillscope run --task clamp --condition baseline --output results/my-baseline-001
```

作用：建立一个最基本的真实参照。它只做一道题、一个配置，不会执行全部排期。

LangGraph 负责固定顺序，可以理解为流程管理员：

| 阶段 | 模型做什么 | 程序保留什么 |
| --- | --- | --- |
| investigate | 分析缺陷 | 一份有长度限制的调查摘要 |
| implement | 提交完整修复代码 | `candidate.py` |
| verify | 检查候选代码 | 模型的检查意见 |
| 独立评分 | 模型不参与判分 | pytest 的真实结果 |

前三个阶段各请求一次模型。模型只能使用预先定义的提交工具；它不能把任意 shell 命令交给宿主机执行。

每个阶段重建消息。修改阶段接收调查摘要，检查阶段接收候选代码；不携带完整旧对话。摘要和代码仍可能传递旧指南的影响，所以阶段切换的效果需要后续实验衡量。

默认模型调用上限为 3 次，每次最多生成 1,024 tokens，无自动重试。输入也会产生 token 用量，这不是固定金额承诺。实际用量在运行结束后记录，费用以 DeepSeek 账户账单为准。

Docker 和镜像先检查，已有输出目录先拒绝，避免因这些问题先花模型调用额度。API 失败、预算耗尽和容器故障分别记录，不伪装成通过或普通答题失败。

## 4. 为什么需要容器外评分

独立测试可以理解为模型看不到的考卷。测试内容不进入提示词，也不挂载进候选容器。

宿主机运行可信测试，通过 JSON 代理发出“调用函数，参数是多少”的请求。候选代码只在容器中执行，返回值再交给外部测试判断。容器没有网络，不接收密钥，只读挂载候选代码文件，并限制用户权限、内存、进程数和执行时间。每次函数调用使用新容器，完成或超时后清理。

当前代理只适用于示例的两道普通 JSON 函数任务，保留顶层参数修改和返回值身份关系；不支持任意对象、跨调用状态或完整仓库测试。后续扩展评测任务时需要相应扩展执行协议。

## 5. 看懂结果文件

| 文件 | 作用 |
| --- | --- |
| `input.json` | 保存本次实验材料快照，不含密钥和评分源码 |
| `trace.jsonl` | 逐行保存阶段、请求内容、模型响应和接口错误状态 |
| `candidate.py` | 模型实际提交的修复代码 |
| `handoffs.json` | 三阶段提交的摘要、代码、检查意见 |
| `grader.log` / `report.xml` | 独立测试的输出和结构化结果 |
| `run.json` | 最终状态、模型、镜像、预算及 token 用量 |

`passed` 表示此次独立测试通过。`failed` 表示正常完成评分但有测试失败。API、环境错误、超时等状态没有正常成绩，不能与普通失败混合计算完成率。金额未知时保持 `null`。

## 6. 验证阶段加载配置

```powershell
.\.venv\Scripts\python.exe -m skillscope run --task clamp --condition scoped --output results/my-scoped-001
```

作用：确认在相同题目上，按阶段加载指南的流程也能运行。这仍只是管道验证，单次结果不能证明阶段策略优于其他配置。

两条命令都会产生 API 调用费用。已有结果不会覆盖，重跑请换输出目录。已完成的本机试运行结果见[试运行记录](smoke-results.md)。
